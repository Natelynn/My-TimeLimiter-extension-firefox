# 🎯 Focus Manager — расширение для Firefox

Помогает контролировать время, проводимое на **Twitch** и **YouTube**.

## Что делает

- Вы задаёте один или несколько **разрешённых интервалов**, например `10:00–13:00`, `16:00–18:00`, `21:00–23:00`.
- **Внутри интервала**: Twitch и YouTube доступны без ограничений, пока не исчерпан лимит минут (лимит задаётся отдельно для каждого интервала, например 1 час).
- **Вне интервалов**:
  - ❌ Twitch полностью заблокирован (страница перекрывается, видео ставится на паузу);
  - ⚠️ YouTube работает, но рекомендации отключены — лента на главной скрыта, блок «Далее»/«Похожие видео» убран. Поиск и прямые ссылки работают как обычно.
- Счётчик времени сбрасывается каждый день (или вручную в настройках). Интервалы могут переходить через полночь (`23:00–01:00`).

## Как установить (5 минут, ничего программировать не нужно)

1. Скачайте/скопируйте эту папку к себе на компьютер (нужна папка `extension`).
2. Откройте Firefox, в адресной строке наберите: `about:debugging#/runtime/this-firefox` и нажмите Enter.
3. Нажмите кнопку **«Загрузить временное дополнение…»** (Load Temporary Add-on…).
4. В диалоге выберите файл **`extension/manifest.json`**.
5. Готово! Иконка 🎯 появится на панели Firefox.

> ⚠️ После перезапуска Firefox «временные» дополнения снимаются — поставьте так же заново (10 секунд), либо подпишите расширение бесплатно на addons.mozilla.org, либо используйте Firefox Developer Edition.

## Как пользоваться

- Клик по иконке расширения → текущий статус: идёт ли интервал, сколько минут Twitch осталось.
- Кнопка **«Открыть настройки»**:
  - включатель расширения;
  - лимиты по умолчанию (минут на Twitch/YouTube в интервале, 0 = без лимита);
  - список интервалов: «＋ Добавить интервал», удаление «✕», у каждого — своё время и свои лимиты;
  - «Сбросить счётчик времени за сегодня».
- Изменения применяются после нажатия **«💾 Сохранить»**.

## Структура

```
extension/
├── manifest.json            # манифест (MV2, формат Firefox)
├── background/background.js # логика интервалов, лимитов, учёт времени
├── content/content.js       # блокировка Twitch, скрытие рекомендаций YouTube
├── content/content.css      # стили оверлея/баннеров
├── popup/                   # всплывающая панель статуса
├── options/                 # страница настроек
└── icons/                   # иконки
```

## Известные ограничения

- Это «мягкий» ограничитель: при желании его можно отключить в `about:addons`. Защита от импульсивного скроллинга, а не от осознанного обхода.
- Если YouTube сменит вёрстку и рекомендации появятся снова — обновите селекторы в `content/content.js` (блок `YT_HIDE_SELECTORS`).
- Время засчитывается, только когда вкладка сайта открыта и видима.
